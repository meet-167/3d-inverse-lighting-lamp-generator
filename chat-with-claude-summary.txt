## What I delivered

### Phase 1: Detailed technical plan (the diagrams)
- Two flowcharts showing the geometry pipeline and system architecture
- Explanation of the core insight: it's not a lithophane (varying thickness), it's a **pierced-shell shadow lantern** (holes cut straight through where the shadow image is white)
- Walkthrough of each step: profile extraction → shadow wrapping → voxel field → marching cubes → mesh repair → STL export
- Why voxels + one marching-cubes pass beats thousands of boolean operations

### Phase 2: Actual working code (9 Python files + HTML)
Not a sketch or pseudocode — **running, tested code**:

- **`geometry/profile.py`** — turns the ring image into a radial function r(θ) via ray-marching
- **`geometry/shadow_map.py`** — wraps the shadow image angularly and creates a solid/hole sampler
- **`geometry/voxel.py`** — builds the 3D voxel field and runs marching cubes
- **`geometry/mesh.py`** — repairs the mesh (remove degenerates, fix normals, fill holes) via trimesh
- **`geometry/decor.py`** — emboss pattern sampling for the cover
- **`geometry/bulb.py`** — parametric bulb holder model
- **`geometry/pipeline.py`** — single entry point tying all six modules together
- **`api.py`** — FastAPI wrapper (POST /generate with 3 file uploads, GET /download/{job}/{part})
- **`viewer.html`** — self-contained Three.js STL viewer (no backend needed)

### Phase 3: Verification
- **Generated 3 working STL files** (shade, cover, bulb) on synthetic test images
- **Caught and fixed 2 real bugs:**
  - Grid padding bug: first version left top/bottom rims open because marching cubes only caps a surface where it sees the solid→empty transition *inside* the grid
  - Image orientation bug: shadow image rows were mapped backwards, making the test tree upside-down
- **Confirmed both final STLs are watertight** via `trimesh.is_watertight`
- **Generated cross-section plots** (5 horizontal slices) proving the star wall + tree holes are correctly carved
- **Generated an unrolled (θ, z) pattern plot** showing exactly where the solid/hole boundary is
